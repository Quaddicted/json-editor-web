No GitHub account or PAT needed: posts the package to quaddicted.com/db/json_upload, which opens the pull request against Quaddicted/quaddicted-data for you. You grant Quaddicted.com/Spirit all rights to the submitted JSON data.

Uses a GitHub PAT with access to Quaddicted/quaddicted-data (classic PAT with repo scope, or a fine-grained PAT with Contents:write and Pull requests:write on all your repositories). The PAT is only sent to api.github.com and, if you save it, stored in localStorage.
